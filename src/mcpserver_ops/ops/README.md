# yunwei-tool

## 项目简介
yunwei-tool是一个运维工具，旨在通过SSH协议远程访问服务器并获取系统日志和容器日志。该工具支持关键字搜索和日志保存功能，方便运维人员进行故障排查和监控。

## 功能
1. 远程访问服务器主机，通过SSH协议连接。
2. 获取远程服务器的系统日志和指定容器的运行日志。
3. 支持指定获取日志的行数，例如最后的50行。
4. 根据日志内容进行关键字搜索，并返回匹配的行。
5. 支持将获取的日志保存到本地文件。
6. 使用Ansible包实现远程命令和任务的执行。

## 安装步骤
1. 克隆项目到本地：
   ```
   git clone <repository-url>
   ```
2. 进入项目目录：
   ```
   cd yunwei-tool
   ```
3. 安装所需的Python库：
   ```
   pip install -r requirements.txt
   ```

## 使用方法
1. 运行主程序：
   ```
   python src/main.py
   ```
2. 根据提示输入所需的参数，例如服务器地址、日志类型、行数等。
